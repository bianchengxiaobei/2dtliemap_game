## 1. 背景与目标

M14-T10 落地了“房间集合剖切”的最小版本，M36-T1/T2 已推进到按格与方向：

- 集合 = 当前房间 + 玩家 ±1.5 格内、朝向前方且视线可达的相邻房间；
- 剖切状态按 z=0 地面格记录，每格 750ms 锁，输入变化才重算；
- 集合内房间的 z≥1 上层按地面格隐藏；
- 只有 manifest 声明 `cutaway` 的墙参与裁切：N 面看自身+E、W 面看自身+S，按 `render.cutawayWallKeepRatio` 压底/列裁并保持墙顶对齐；
- 其余遮挡墙按 `render.wallOcclusionAlpha` 淡出。

对照反编译源码，PZ 的可见性系统还有 7 类行为未覆盖：**按格标志、复杂资格判定、sprite 级剖切标记、方向性遮罩、窗口扒看、整栋建筑遮挡、屋顶归属**，另有独立的**植被压平**。

本里程碑目标：

1. 把“剖切”从房间级细化到格级，并去掉逐帧射线重算；
2. 让裁切形状/范围接近 PZ 的方向性效果，且不再误裁栅栏、门框等非墙结构；
3. 补齐“站在室外/房后被建筑挡住”和“隔窗看屋内”两类高频场景；
4. 补齐屋顶归属规则与树冠压平，避免误删相邻建筑屋顶、树挡人；
5. 全程保持：不改存档、不改联机协议、不改碰撞/寻路/AI，所有新行为可配置关闭并回退到 M14-T10 行为。

## 2. 范围与非目标

**范围内**

- 单机与联机客户端（纯客户端表现；服务器不参与）；
- 砖房/木屋、玩家自建墙门、村庄与 POI 建筑；
- z=0 与 z≥1 的上层/屋顶；
- 树冠等大型植被遮挡；
- 1280×720 与 1920×1080；
- 配置开关、单测、性能预算、手动验收清单。

**非目标**

- 分屏/多玩家独立剖切（PZ 的 4 个 `playerIndex` 标志；本项目单相机，不做）；
- 精确复刻 PZ 的 `wallcutaways.png` 遮罩与全部特例 sprite（车库/教堂/拖车等）；
- 楼梯、可攀爬窗、跨楼层实体可见性（归 M31 无缝大地图后续）；
- 屋顶坍塌、建筑结构破坏后的动态重建（沿用现有 ChunkDiff 结构逻辑，不在本里程碑改）；
- 修改地图文件格式（优先运行时推导建筑；确需字段时单独评审）。

## 5. 设计约束与总原则

1. **每格状态、脏重算**：新增 per-square 剖切状态；只有触发源变化才重算，禁止逐帧在 `ApplyWallOcclusion` 里做 O(格×射线)。
2. **渲染层只读**：剖切只改当帧 `DrawItem`（颜色/rect/UV），不回写 world / ECS / 存档 / 联机复制。
3. **配置可回退**：每个新行为一个开关；关闭时逐项退回 M14-T10 语义，且 M14-T10 单测保持通过。
4. **数据驱动标记**：sprite 是否可剖、是否植被、是否窗，全部走 `asset_manifest.json` 元数据，不按 sprite 名字硬编码。
5. **纯函数优先**：判定/锁/选择逻辑抽到可单测的纯函数（新头文件），`WorldDemoState` 只负责取世界数据与落地。
6. **先单机后联机**：表现层不涉及协议；但每个 T 结束跑一次双客户端冒烟，确认无崩溃/无状态污染。
7. **性能预算**：常规场景剖切更新 ≤ 0.2ms/帧；重算时每帧射线 ≤ 16 条；不增加 drawcall/批次，不降低 500 僵尸场景帧率。
8. **不复制 PZ**：禁止照抄常量、纹理矩形、字段命名；参考只用于确认“行为存在与否”。

## 11. 风险与回退

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 建筑推导把相邻房屋并成一栋 | 误删屋顶/墙 | 以房间矩形连通 + 间隙 ≥1 格断开；T5 用例锁定 |
| 逐格标志带来全表扫描 | 帧时间上升 | 脏标记 + 只遍历可见 grid stack；性能预算门禁 |
| 方向裁切在斜角出现缝隙 | 观感瑕疵 | 相邻格标志扩大裁边；保留 `ratio` 模式回退 |
| 窗内容影响寻路/僵尸 | 卡怪 | 窗按墙处理（阻挡）；冒烟 `M5*` + 手动 |
| 联机客户端表现差异 | 玩家困惑 | 纯客户端表现、无协议改动；双客户端冒烟 |
| 遮罩美术工期 | 阻塞 T2 | 先纯几何裁剪；遮罩作为可选增量 |
| 误改存档/复制字段 | 兼容性事故 | 本里程碑禁止改存档 codec / ZLR1 / PlayerState |
