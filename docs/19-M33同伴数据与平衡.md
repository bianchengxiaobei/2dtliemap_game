# M33 同伴数据与平衡

> 状态：M33-F3-T1~T8 完成（2026-11-14）。本文档记录 `companions-v1` 内置内容、招募条件、战斗/AI 平衡参数、联机边界与 T8 验收结果。

## 1. 内容契约

- 基础文件：`assets/companions.json`，格式 `companions-v1`。
- mod 文件：`mods/<id>/content/companions.json`，按加载顺序追加，不能覆盖基础定义。
- 必填：`id`、`name`；其余字段缺省值见 [docs/modding.md](modding.md) 的同伴章节。
- 同伴定义进入内容指纹 v19（M33-F4-T1 起整体 v20，M33-F5-T1 起 v21）；客户端与服务器定义不一致会在握手阶段拒绝。
- 生命复用通用 `ecs::Health`；`CompanionState` 保存信任、指令、待命/倒地/死亡、背包、装备、个人委托和额外特长。

## 2. 内置同伴

首个版本每个玩家最多拥有 1 名活动或待命同伴；两名内置同伴分别归属不同聚落和前置任务。

| 字段 | 林医生 `companion_medic_lin` | 阿默 `companion_scout_amo` |
|---|---|---|
| 聚落 | 村庄营地 | 南部农场 |
| 基础生命 | 95 | 115 |
| 初始信任 | 55 | 40 |
| 主手 | 厨刀 | 简易长矛 |
| 躯干 | 夹克 | 加固夹克 |
| 背包容量 | 10 kg | 14 kg |
| 初始物资 | 绷带×2、罐头汤×1 | 能量棒×2、绷带×1 |
| 特长标签 | `field_medic`、`steady_hands` | `scout`、`cool_headed` |
| 最低声望 | Friendly | Friendly |
| 前置任务 | `settlement_help` | `south_harvest_help` |
| 招募物资 | 绷带×2 | 罐头汤×1 |
| 对话 profile | `companion_lin` | `companion_amo` |

### 2.1 个人委托

- 林医生：赠送绷带→与林医生击杀感染者；奖励 `triage_drills`/急救包、`steady_hands_ii`/皮夹克。
- 阿默：赠送罐头汤→与阿默击杀感染者；奖励 `trailwise`/砍刀、`cool_headed_ii`/加固夹克。
- 奖励按 `personalRewardMask` 防重复；死亡或显式放弃会中止当前阶段，可重新接取。
- 个人委托是同伴专属链，不写入全局 `MissionLog`。
- `traits`/`extraTraits` 当前是持久化内容标签，不直接修改武器数值；战斗差异主要来自主手武器、护甲和 AI 参数。

### 2.2 对话差异

- `dialogueProfile=companion_lin`：闲聊偏医疗、绷带和“低头救人”。
- `dialogueProfile=companion_amo`：闲聊偏路线、撤退和地平线。
- 低血/受伤文本也不同；信任档、低血、倒地、死亡和个人委托状态仍共用统一条件分支。

## 3. 战斗平衡

### 3.1 DPS 公式

玩家轻击理论 DPS：

```text
playerDps = weapon.combat.damage / weapon.combat.cooldown
```

同伴有效 DPS：

```text
companionDamage  = weapon.combat.damage * companions.ai.attackDamageScale
companionCooldown = weapon.combat.cooldown * companions.ai.attackCooldownScale
companionDps     = companionDamage / companionCooldown
```

默认 `attackDamageScale=0.38`、`attackCooldownScale=1.20`，即同伴使用同一主手武器时理论 DPS 为玩家的 **31.67%**。空手同伴使用独立回退值 `attackDamage=24`、`attackCooldown=0.85`，约为玩家空手 DPS 的 **35.3%**。

| 同伴 | 主手 | 同伴 DPS | 同武器玩家 DPS | 比例 |
|---|---|---:|---:|---:|
| 林医生 | 厨刀 | 41.56 | 131.25 | 31.67% |
| 阿默 | 简易长矛 | 28.79 | 90.91 | 31.67% |
| 空手回退 | - | 28.24 | 80.00 | 35.29% |

### 3.2 受伤与倒地

- 同伴仍使用通用伤害管线，可被僵尸、火焰、环境、范围伤害和脚本伤害命中。
- 生命 ≤30% 自动撤退，恢复到 50% 解除；倒地窗口 60 秒，2.5 格内救援恢复 35% 最大生命。
- 窗口结束死亡，装备/背包转入 `companion_corpse` 尸体容器，不复制物品。
- 因此单同伴提供有限火力与承伤，不替代玩家走位、格挡、闪避和资源管理。

### 3.3 AI/平衡配置

全部参数位于 `config/game.json` 的 `companions.ai`：

| 键 | 默认值 | 作用 |
|---|---:|---|
| `followDistance` | 3.0 | 跟随目标距离 |
| `followMin` / `followMax` | 1.8 / 4.5 | 跟随即停区间 |
| `ownerEngageRadius` | 6.0 | owner 威胁获取半径 |
| `ownerUrgentRadius` | 3.5 | 直接威胁半径 |
| `leash` | 12.0 | 追击/脱战 leash |
| `freezeRadius` | 40.0 | 远距离冻结 |
| `attackRange` | 1.35 | 空手回退攻击距离 |
| `attackDamage` | 24.0 | 空手回退伤害 |
| `attackCooldown` | 0.85 | 空手回退冷却 |
| `attackDamageScale` | 0.38 | 主手武器伤害缩放 |
| `attackCooldownScale` | 1.20 | 主手武器冷却缩放 |
| `attackKnockback` | 1.1 | 攻击击退参数 |
| `attackStagger` | 0.25 | 攻击硬直参数 |
| `lowHealthFraction` | 0.30 | 自动撤退阈值 |
| `recoverHealthFraction` | 0.50 | 解除自动撤退阈值 |
| `stayEngageRadius` | 4.0 | 停留迎战半径 |
| `stayLeash` | 4.5 | 停留追击上限 |
| `trapClearance` | 0.8 | 陷阱落点避让 |
| `pathRetrySeconds` | 0.35 | 路径重试间隔 |
| `downedSeconds` | 60.0 | 倒地窗口 |
| `rescueHealthFraction` | 0.35 | 救援恢复比例 |
| `rescueRange` | 2.5 | 救援距离 |
| `combatKillTrust` | 2 | 同伴击杀信任增量 |

读取时会做范围 clamp，并把 `followDistance`、`followMax`、`ownerUrgentRadius`、`leash`、`freezeRadius`、`recoverHealthFraction`、`stayLeash` 校正到互相一致的区间。

## 4. 联机与交互边界

- 联机只复制装备摘要，不复制完整背包；客户端面板显示“背包未同步”。
- 服务器权威处理招募、解散、跟随/停留/撤退、赠礼、个人委托接取/放弃、救援。
- 玩家断线/死亡/同身份接管时同伴回聚落待命；重连恢复 owner 关系但不自动召回。
- 不做 RTS 框选、编队、逐单位微操；不做换装/服药/装填面板；不做好感度恋爱线。
- 同伴 `traits` 目前不改变伤害/护甲公式，避免与武器、护甲和 M30 战斗规则形成第二套数值真源。

## 5. T8 验收

- 内容：2 个内置定义，特长/装备/对话/招募任务与物资料不同。
- 平衡：两名内置同伴的同武器 DPS 比例均为 31.67%，空手回退 35.29%，落在 30%–50% 验收区间。
- 自动化：`M33-F3-T8*`、`M33-F3-*`、聚落/战斗/网络回归、Debug/Release/Python 全量。
- 双客户端：两名玩家分别通过正常 `E` 对话招募 1 名同伴，运行 15 游戏分钟，检查面板、生命和 HUD；截图见 `build/m33_f3_t8_dual_smoke/`。
- 启动烟测：默认同伴 2 个、世界事件 6 个、内容指纹 v19（F4-T1 起 v20，F5-T1 起 v21）、stderr 为空。
- 详细测试计数与烟测记录回填在 `docs/18-M33世界内容扩展.md`、`docs/devlog.md` 和 `docs/07-视觉与交互验收.md`。
