## 1. 结论与推荐顺序

| 优先级 | 功能包 | 解决的问题 | 建议周期 |
|---|---|---|---|
| P0 | M18 基地生活与经营 | 基地目前只是防线，缺少储物、饮食、睡眠和建造扩展 | 5~8 天 |
| P1 | M19 角色成长与探索 | 缺少长期成长目标，地图和任务内容偏少 | 8~12 天 |
| P2 | M20 威胁与生存深度 | 缺少感染、天气、特殊威胁和后期经营 | 10~15 天 |
| 横切 | 联机、Mod、质量收尾 | 建造不能联机、API 与验收债 | 5~10 天，穿插进行 |

推荐顺序：**先把 M18 做成一个完整可验收的垂直切片，再决定 M19/M20 的具体投入**。不建议先做联机建造同步、NPC 或车辆，这些会放大当前单机内容不足的问题。

## 3. M18 基地生活与经营

**目标**：让基地从“守夜用的栅栏”变成可居住、可整理、可恢复、可长期经营的据点。

**总体验收**：新档 30~60 分钟内完成一次“搜刮 → 建仓库 → 存物资 → 烧水/做饭 → 睡觉 → 第二天取物资/维修”的循环；不依赖调试命令；存档/重载和 chunk 卸载后物品不丢失、不复制。

### M18-F1 玩家储物与基地库存（已完成，2026-10-24）

**玩家体验**

- 可建造木箱/储物柜，靠近后打开仓库界面。
- 可将背包物品存入、取出、全部存入、全部取出；支持按类别/重量排序。
- 仓库容量有限，超重/超格时给出明确提示，不吞物品。
- 拆除仓库时，内容物掉落到地面或转移到玩家背包；不能凭空消失。
- 仓库在存档、退出重进、chunk 卸载/重载后保留。

**功能需求**

- 新增玩家仓库建筑类型，默认消耗木材；容量/重量可配置。
- 仓库物品使用现有 `Container` 数据模型，复用 `items::MoveStack`/容量校验。
- 仓库与地图自带搜刮容器明确区分：搜刮容器一次性 roll，玩家仓库可反复存取。
- 新增 `StorageId` 或等价稳定标识，保证 tile 对象与仓库内容长期关联。
- 拆除/摧毁仓库统一走“先处理内容物，再移除对象”的路径，避免遗留孤儿库存。
- 仅单机开放；联机模式拒绝建造和存取，不破坏现有同步。

**UI/输入**

- 靠近仓库显示交互提示；打开现有背包面板并切换到“仓库”区域。
- 增加“全部存入/全部取出/整理”按钮；保留现有拖拽和右键操作。
- 仓库为空、容量不足、目标不可用时有 HUD 提示。

**存档/兼容**

- 仓库内容和稳定 ID 必须进入存档；旧存档没有仓库数据时按空仓库处理。
- chunk 卸载不销毁仓库记录；重载不生成重复仓库。
- 已定稿为带 `PlayerStorage` 标记的 ECS 实体；容量/堆数上限随实体存档，旧存档缺少组件时按无仓库处理。

**验收**

- 建仓库、存 3 种物品、退出重进后数量和耐久/状态一致。
- 拆仓库后物品完整落到地面或背包；重载不复活仓库、不复制物品。
- 容量不足时不部分吞物品；仓库满时“全部存入”有明确反馈。
- 联机模式不能建造/打开玩家仓库。

**实现记录（2026-10-24）**

- 采用 ECS 仓库实体：`Position + SpriteRef + Container + PlayerStorage`；实体 StableId 即稳定标识，避免 tile/chunk 生命周期耦合。
- 新增 `PlayerStorage` 存档组件（容量/堆数上限写入 `Container`/组件）；旧存档缺少组件时不影响其他实体加载。
- 建造项 `storage`：`object.crate` 外观、4 木材、50kg、6 堆；建造后为 ECS 实体，不占 tile 阻挡层。
- 背包右侧在靠近仓库时切换为“仓库”内容；支持拖拽、全部存入、全部取出、整理、右键拾取/装备；拆除仓库时先转移到背包，剩余掉地，再销毁实体并返还木材。
- 单机开放；联机模式 `FindNearbyStorage` 返回空，服务端仓库动作返回“联机模式暂不支持玩家仓库”。
- 测试：`test_storage` 覆盖生成/查找、容量/堆数、全部转移、拆除内容清空、实体存档；`test_ui` 覆盖仓库按钮；Lua/Python `Inventory` 动作解析覆盖 `store_all/take_all`。
- 仓库内“整理”按物品类型、defId、状态排序，不改变物品数量/耐久。

**风险**

- 仓库采用 ECS 实体后不参与 tile 碰撞/A*；如后续需要僵尸破坏仓库，需补 HP 与结构目标逻辑。
- 仓库实体数量增长时的存档体积和加载耗时仍需基准测试。

### M18-F2 饮水、烹饪与食物保鲜（已完成，2026-10-24）

**玩家体验**

- 水壶可以在水源装水，篝火烧水后变成安全饮用水。
- 生食/简单食材可以在篝火加工；熟食恢复更多饥饿值。
- 食物会随时间变质，玩家需要规划储备，而不是无限囤积。
- HUD 显示口渴、食物状态和“需要烧水/食物将坏”的提示。

**功能需求**

- 增加水源交互：水槽/水桶/雨水收集器至少一种；优先复用地图对象，不新增大型美术。
- 增加液体容器状态：容量、当前水量、是否煮沸/污染。
- 增加食物新鲜度/腐败时间；按游戏时间推进，暂停不衰减。
- 扩展 `recipes.json`：烧水、简单烹饪；制作站仍使用篝火。
- 腐败食物不直接删除，转为“变质”状态；食用有风险，风险强度可配置。
- 不引入完整燃料系统；如需要，先以配方时间/一次性消耗表达。

**UI/输入**

- 背包物品显示水量/新鲜度；水壶右键“装水/倒水”。
- 篝火附近显示可制作配方；不可制作原因明确（缺工具/缺材料/缺水源）。
- HUD 口渴警告和食物将坏提示。

**验收**

- 空水壶装水、烧水、饮用后口渴恢复；脏水与熟水的状态可区分。
- 食物在设定时间后进入变质状态；存档/重载后剩余保鲜时间不回满。
- 制作失败不消耗材料；容量不足不吞物品。
- Python 资源测试覆盖新增物品/配方字段。

**风险**

- 液体和新鲜度如果直接扩展现有 item 定义，可能影响旧存档和堆叠逻辑；需要可选字段与默认值。
- 腐败时间过短会让搜刮失去意义，过长则系统没有存在感；先给保守默认值并在验收中调整。

**实施记录（2026-10-24）**

- 液体：`empty_bottle`（空瓶，1L）→ `dirty_water`（脏水，1L）→ `water_bottle`（净水，1L）。饮水后通过 `use.replaceWith` 原位回收空瓶；`maxStack=1`，F2 不实现部分水量/倒水，容量固定 1L，污染/煮沸状态由物品 id 区分。
- 水源与制作站：新增可建造“雨水收集器”（5 木材，`object.locker` 占位，制作站 id `locker`）；`fill_bottle` 在雨水收集器旁把空瓶装满脏水；`boil_water` 在篝火旁把脏水烧成净水。`crafting.stationLabels` 增加“雨水收集器”。
- 风险：脏水饮用恢复 0.25 口渴并扣 4 HP（`use.healthPenalty`）；净水恢复 0.4。制作失败仍走原子 `Craft`，不消耗材料。
- 保鲜：`ItemDef.spoilDays`（可选，0 = 不腐败）与 `ItemInstance.condition` 复用为新鲜度；`cooked_beans` 为 1 天。`WorldSimulation` 每累计 1 游戏分钟推进所有 `Container` 与地面物品，暂停不衰减；`food.spoilScale` 可调。

- 验证：`test_food` 覆盖字段解析、空瓶回收、腐败推进、变质使用、装水/烧水配方链；`test_world` 覆盖 `locker` 站点查询；Python `test_food_data` 覆盖资源契约。

### M18-F3 睡眠与休息（已完成，2026-10-24）

**玩家体验**

- 建造/放置床或睡袋后，可以睡到指定时间。
- 睡眠恢复疲劳，但会推进饥饿/口渴，并可能被僵尸/守夜事件打断。
- 玩家需要选择“今晚守夜还是睡觉”，形成日常取舍。

**功能需求**

- 新增床/睡袋建筑或可交互对象；靠近显示“睡觉”提示。
- 睡眠菜单支持 1~8 小时或“睡到天亮”；时间加速，画面可淡出/简单遮罩。
- 睡眠期间 Needs 继续消耗；疲劳按配置恢复。
- 受到伤害、僵尸接近、守夜事件开始、玩家主动取消时中断睡眠。
- 睡眠结束/中断时给出时间、疲劳和中断原因提示。
- 单机优先；联机模式先禁用睡眠，避免时间同步问题。

**验收**

- 睡 6 小时后疲劳下降、饥饿/口渴按时间推进；天亮时间正确。
- 守夜事件或受伤能打断睡眠，不出现睡眠中继续被围攻但无提示。
- 存档发生在睡眠前后不产生重复时间推进或状态丢失。
- 联机模式不出现单方面跳时间。

**风险**

- 时间加速与固定 tick、存档、事件计时可能互相影响；必须将“睡眠”作为独立时间推进状态，而不是简单改倍速。

### M23-F3-T3 蔓延规则（2026-10-29）

- `FireSystem` 的 `Burning` 源按 `FireSpreadInterval(burnSeconds)` 累计脉冲并只向同层四邻接（上/下/左/右）尝试蔓延；间隔按 `spreadIntervalSeconds × (0.5 + clamp(burnSeconds/60, 0, 3))` 计算，木地板（45 秒）快于木墙（90 秒）和树木（120 秒），草丛最快、篝火最慢。
