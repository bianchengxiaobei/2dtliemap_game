## 1. 目标体验

玩家可以用三种方式处理同一片威胁区：

1. **潜行接近**：按住/切换低姿态，降低脚步噪声与可视距离，绕开视线，接近未警觉目标后打出一次背刺；被发现后仍能正常战斗、格挡和逃跑。
2. **投掷制造机会**：把石头、长矛或燃烧瓶扔到指定位置，制造噪声、击伤目标或点燃区域；投掷物有射程、落点、噪声和可回收/损坏差异。
3. **陷阱控制区域**：在基地或 POI 入口布置捕兽夹、绊线警报和燃油陷阱，利用噪声、定身和火焰改变敌人的进攻路线；陷阱可布防、解除、拆除并随存档恢复。

希望形成的最小循环：

> 潜行观察敌人 → 用投掷物制造声音/火点 → 把敌人引到陷阱区 → 背刺或撤退 → 回收可回收投掷物 → 存档/读档后陷阱和火焰仍存在。

M34 不要求把三种玩法做成完整技能树；先做可反复使用、可联机、可存档的底层闭环。

## 2. 非目标

本阶段明确不做：

- 不做完整潜行技能树、夜视、伪装、开锁、扒窃、尸体隐藏或“完全隐身”。
- 不做全物品通用投掷；只有显式标记 `throwable` 的物品可投掷。
- 不做手雷、炸药、火箭、弹道反弹、风偏、复杂刚体碰撞或投掷物逐帧物理模拟。
- 不做远端逐帧投掷物实体复制；远程客户端以投掷音效、命中结果和落地物品/火焰为准。
- 不做可携带式捕兽夹/绊线/地雷道具；M34 的陷阱先走现有建造模式放置。可携带陷阱留后续。
- 不做陷阱对玩家的默认伤害；PvP 陷阱、队友伤害和拆陷阱小游戏不在本阶段。
- 不做专用动画、正式角色/动物美术、正式混音、语音或新 Boss。
- 不做 RTS 框选/编队、多单位操控、动态光照/阴影、跨机 NAT 或独立潜入服务器。
- 不做联机动态 mod 热重载；内容变化仍要求服务器和所有客户端重启后重新握手。

### 3.1 关键实现事实

- M34 已新增独立潜行键 `N`（可改键）；旧版动物只能靠树木遮挡接近。M34 是新功能，不是补旧任务。

- 现有尖刺陷阱是 `ecs::SpikeTrap`，单机只扫描 `BaseSiegeZombie`（`src/game/states/WorldDemoState.cpp:18421`），服务器只扫描 `BaseSiegeZombie`/`SettlementRaidZombie`（`src/server/ServerHost.cpp:13729`）；不要直接把新陷阱塞进旧 `SpikeTrap`，避免破坏旧存档/旧触发语义。
- 现有建造只扣木材（`BuildingRules.h` 的 `woodCost`）；M34 新陷阱先使用木材成本，不新增货币/材料系统。
- `PlayerState` 当前 v23；保留 v22 解码路径，旧负载默认站立/零噪声。ZLR1 当前注册 33 个组件（F3-T1 新增 `TRAP2`）。

## 4. 操作与设计定稿

### 4.1 默认操作

| 操作 | 默认键 | 说明 |
|---|---|---|
| 潜行切换 | `N` | 站立/低姿态切换；可在 `input.bindings.Stealth` 改键 |
| 投掷 | `V` | 主手/当前快捷栏为 `throwable` 时投掷；否则沿用枪械 `FireRanged` |
| 放置陷阱 | `B` + 左键 | 复用建造模式，滚轮选择陷阱类型 |
| 布防/解除陷阱 | `E` | 靠近已放置陷阱时切换 armed 状态 |
| 拆除/回收 | `X` | 复用拆除确认，返还木材，不返还成品道具 |
| 取消瞄准/建造 | `ESC` | 沿用现有取消路径 |

`N` 与联机睡眠投票的 `SleepVoteNo` 共用默认键；睡眠/投票界面在 `HandleFrameInput` 前段直接 return，因此不会触发潜行切换。`Stealth` 进入设置菜单并可改键。`V` 不新增键位，只增加“投掷物优先”的上下文。所有新动作必须写入 `config/game.json` 和 `kDefaultBindings`，并能在设置菜单改键。

### 4.2 潜行规则

- 低姿态移动速度 `crouchSpeedScale=0.55`，脚步噪声 `stepNoiseScale=0.45`，被视觉发现距离 `visibilityScale=0.65`。
- 近距全向感知仍保留：贴脸时不能因为蹲下而完全隐身。
- 攻击、投掷、受到伤害、进入载具、进入倒地/死亡状态会退出潜行；退出后不自动恢复。
- 背刺只对“未警觉且位于目标背后扇区”的 AI 目标生效：
  - 未警觉：`AiState` 不处于 `Chase/Attack/SearchLastKnown`，且 `PerceptionState.alertness < 0.5`。
  - 背后：玩家方向与目标 `Facing` 的反方向夹角 ≤ `backstabHalfAngleDegrees=60`。
  - 倍率 `backstabMultiplier=1.6`，只作用于一次近战命中；不做一击必杀。
- M34 默认不做玩家对玩家的背刺；PvP 背刺留后续。
- 潜行姿态不写存档；读档/重生/服务器重连默认站立。

### 4.3 投掷规则

- 只有 `items.json` 中带 `throwable` 的物品可以投掷。
- 投掷目标为鼠标指向的世界格；超出射程时夹到最大射程，遇到墙体/不可达落点时落在最后一个可用格。
- 投掷物使用短时抛物线表现，服务器按落点结算；不做逐帧刚体、弹跳和风向。
- 落点结算：
  - 在 `impactRadius` 内选择最近的可受伤目标，造成 `damage`。
  - 生成 `noiseRadius` 的 `SoundEvent`，复用 AI 听觉和音频。
  - `returnable=true` 且未损坏时在落点生成地面物品，可再次拾取。
  - `breakChance` 命中后按确定性/服务器随机结算损坏；损坏则不生成地面物品。
  - `fire` 字段存在时，落点创建/点燃现有 `FireSource`，不新建第二套燃烧系统。
- 投掷开始时从背包或主手扣除 1 件，防止服务器重启/断线期间复制；未落地前物品由服务器“在飞账本”持有。
- 投掷冷却 `throwCooldownSeconds=0.7`，由服务器和单机共同校验；客户端只做表现。

### 4.4 陷阱规则

M34 新增 3 种**可建造阵地陷阱**，旧 `SpikeTrap` 和电网保持不变：

| 类型 | 建造 id | 木材 | 效果 | 次数 | 触发目标 |
|---|---|---:|---|---:|---|
| 捕兽夹 | `bear_trap` | 3 | 55 伤害 + 2.0 秒硬直/定身 | 4 | 僵尸、动物 |
| 绊线警报 | `tripwire_alarm` | 1 | 18 格噪声，无伤害 | 8 | 僵尸、动物 |
| 燃油陷阱 | `fuel_trap` | 4 | 1.5 格火焰，45 游戏分钟 | 1 | 僵尸、动物 |

- 默认直接伤害不作用于玩家/友方 NPC；燃油陷阱生成的火焰沿用现有火焰规则，进入火区的玩家/同伴仍可能被烧到，提示与测试必须覆盖这一点。同伴 AI 继续避开武装陷阱。PvP 陷阱留后续。
- 放置后 `armSeconds=1.0` 内不触发；可 `E` 布防/解除，`X` 拆除并按 `demolishRefundRatio` 返还木材。
- 触发时选择半径内最近的一个有效目标；消耗 1 次并进入冷却；次数归零自动解除。
- 燃油陷阱调用现有 `FireSystem`，火焰蔓延/伤害/存档沿用 M23 规则；不新增火焰协议。
- 通用状态使用新组件 `PlacedTrap`，旧 `SpikeTrap` 不迁移、不复用其 `TRAP v1` 存档格式。

### 5.2 `items-v1` 的 `throwable`

在物品定义中新增可选对象：

```json
"throwable": {
  "range": 8.0,
  "damage": 8.0,
  "impactRadius": 0.6,
  "arcHeight": 1.0,
  "noiseRadius": 6.0,
  "returnable": true,
  "breakChance": 0.0,
  "fire": { "radius": 0.0, "minutes": 0.0 }
}
```

字段校验：

- `range` 1–16，`damage` 0–80，`impactRadius` 0–3，`arcHeight` 0–3，`noiseRadius` 0–32。
- `breakChance` 0–1；`fire.radius` 0–3，`fire.minutes` 0–240。
- 未带 `throwable` 的物品保持旧行为，不能投掷。
- `forage_stone`、`makeshift_spear`、`bone_spear` 增加 `throwable`；新增 `molotov` 物品与配方。具体数值在 F2-T1/T4 固定，F2-T6 平衡、F2-T7 回归锁定。

## 12. 风险与控制

| 风险 | 控制 |
|---|---|
| 潜行导致 AI 永久失去目标/难度骤降 | 只缩放视距/噪声，不做完全隐身；保留近距全向感知和 lastKnown；固定距离回归 |
| 背刺破坏战斗平衡 | 仅未警觉 AI、仅一次近战、1.6 倍、不暴击/不秒杀；PvP 不做 |
| 投掷物复制/丢失 | 服务器投掷开始即扣物，在飞账本；存档/退出前结算；断线/重启用例 |
| 投掷落点/墙体异常 | 夹取射程、最后可用格、有限值校验；无效命令拒绝 |
| 旧陷阱被重构破坏 | 新 `PlacedTrap` 与旧 `SpikeTrap` 分离；旧 `TRAP v1` 路径只读兼容 |
| 陷阱每 tick 全图扫描 | 只扫描已加载/半径内候选；20 陷阱性能用例；触发后冷却 |
| 陷阱误伤友方/玩家 | 默认 triggerMask 只含 zombie/animal；同伴避让；PvP 留后续 |
| 内容/协议版本过多 | 按 F2/F3 两次集中升级；旧解码保留；每次升级补握手/旧档测试 |
| 输入冲突 | `N` 空闲；`V` 上下文；陷阱复用 `B/E/X`；所有动作可改键 |
| 正式表现不足 | M34 只做占位/程序化表现；正式动画/音效明确不在范围 |
