## 2. 目标与非目标

### 2.1 玩家体验目标

- **轻击**：快、省体力、低破防，适合清理普通僵尸和打断轻攻击。
- **重击**：慢、耗体力、高伤害/高破防，适合打重甲、强壮的敌人，但空挥惩罚大。
- **格挡**：按住后减伤但消耗体力；体力耗尽会破防。
- **弹反**：格挡开始后的短窗口内完美防反，零伤害并硬直攻击者。
- **闪避**：短距离位移 + 无敌帧，消耗体力，不能无脑连续使用。
- **硬直/破防**：重击和弹反能制造更长硬直；轻击只能短暂打断。
- 玩家需要看敌人前摇、管理体力、选择“轻击清杂 / 重击破防 / 格挡等待 / 闪避绕后”。

### 2.2 非目标

- 不做部位伤害、断肢、骨折、精确碰撞盒或逐骨骼受击。
- 不做连招树、武器招式编辑器、盾牌、双持、蓄力长按、处决动画。
- 不重做远程武器、枪械弹道、车辆战斗或僵尸群体战术。
- 不新增正式美术/音效资源；表现复用现有动画、tint、火花/音效占位。
- 不做“每个敌人独立攻击令牌/包围站位”这类战术 AI 2.0。
- 不改变现有 `DamageType` 语义；火焰/调试伤害不参与格挡。

## 3. 核心规则

### 3.1 战斗体力（Combat Stamina）

新增运行时组件 `ecs::CombatStamina`：

```text
current      当前体力
max          基础最大体力，默认 100
regenDelay   距离开始回复的延迟
exhausted    体力耗尽锁定
```

- 有效最大体力：`max * (1 - 0.30 * clamp(fatigue,0,1))`。
- 回复速度：`18 * (1 - 0.50 * clamp(fatigue,0,1))` 点/秒。
- 消耗后 0.80 秒才开始回复；受击、格挡、闪避都会重置延迟。
- 体力 ≤5 时进入 0.60 秒 `exhausted` 锁定；锁定期间不能攻击/格挡/闪避。
- `Needs.fatigue` 仍是长期疲劳，只影响最大体力/回复；HUD 体力条改为显示 `CombatStamina`，疲劳继续显示在状态文本。
- 不写存档；读档/重连按当前疲劳重新初始化满体力。

### 3.2 轻击与重击

新增 `AttackKind { Light, Heavy }`。`AttackIntent` 增加运行时字段：

```text
kind
windupSeconds     前摇总时长
windupLeft        剩余前摇
poiseDamage       对目标硬直条的伤害
staminaCost       动作开始时扣除
```

攻击时间轴：

1. 输入/服务器命令按目标方向和武器参数写 `AttackIntent`，设置 `pending=true`、`windupLeft=windupSeconds`，立即扣体力并进入攻击动作。
2. `CombatSystem::Update` 每个 tick 递减 `windupLeft`；归零时只做一次扇形命中，然后清 `pending`。
3. 前摇期间被硬直/死亡/上车/切武器/打开背包打断时取消，不造成伤害；已扣体力默认不退（重击可在 T3 评估半退）。
4. AI 仍由 `AiSystem` 管理前摇并直接 `pending=true`；`windupSeconds` 默认 0，保持现有 AI 行为。

基础攻击参数：

| 项目 | 轻击 | 重击 |
|---|---|---|
| 输入 | `SPACE` | `LSHIFT` |
| 前摇 | `clamp(0.06 + weight*0.02, 0.06, 0.18)` | `clamp(轻击前摇+0.22, 0.30, 0.55)` |
| 体力 | `clamp(6 + weight*3, 8, 18)` | `clamp(轻击体力*2.0, 18, 36)` |
| 伤害 | 武器 `damage` | 武器重击覆盖，否则 `damage*1.65` |
| 范围 | 武器 `range` | 轻击范围 +0.10 |
| 扇角 | 武器 `arc` | 轻击扇角 ×0.90 |
| 冷却 | 武器 `cooldown` | 轻击冷却 ×1.55 |
| 击退 | 武器 `knockback` | 轻击击退 ×1.25 |
| 硬直 | 武器 `stagger` | 轻击硬直 ×1.25 |
| 磨损 | 武器 `wear` | 轻击磨损 ×1.25 |
| 硬直条伤害 | `clamp(2 + weight*1.5, 3, 12)` | `clamp(8 + weight*7, 12, 45)` |

- 轻击/重击都保留现有自动瞄准 3 格，目标方向在动作开始时锁定；重击不额外扩大瞄准距离。
- 体力不足、`exhausted`、格挡中、闪避中、硬直中、驾驶中不能起手。
- 重击允许武器数据 `heavy` 覆盖；没有 `heavy` 的旧物品按上表派生。
- 重击不改变 `DamageType`，仍以 `Blunt` 进入伤害管线。

### 3.3 硬直条（Poise）

新增运行时组件 `ecs::Poise`，只给 AI/动物等可硬直目标：

```text
current      当前硬直条
max          最大硬直条
regenDelay   停止受击后的回复延迟
```

- 变体最大硬直条：普通 **20**、快速 **14**、强壮 **32**、重甲 **55**；动物默认 **18**（T5 暂不初始化，保持既有动物受击规则）。
- 重甲对 `0 < poiseDamage < 16` 的轻击不产生基础硬直（仍扣血/扣硬直条/闪红），重击 `>=18` 正常打断；破防长硬直不受此阈值影响。
- 每次有效近战命中先扣 `poiseDamage`；硬直条归零时：
  - `HitReaction.staggerLeft = max(原值, 0.55)`；
  - 清空当前硬直条，1.20 秒后以 10/s 回复到 `max*0.60` 后继续正常回复；
  - 重甲/强壮可被重击破防，但轻击很难直接破防。
- `DamageEvent` 增加可选 `poiseDamage`，由 `CombatSystem` 从 `AttackIntent.poiseDamage` 复制；环境/车辆/火焰事件默认 0。
- `Poise` 不存档、不复制；读档/生成时按变体重新初始化。
- 保留现有 `DamageEvent.staggerSeconds` 作为“每次命中的短硬直”；硬直条归零额外提供 0.55 秒长硬直。T5 根据手感决定轻击是否降低基础硬直。

### 3.4 格挡与弹反

新增运行时组件 `ecs::CombatStance`（玩家/可格挡 NPC）：

```text
blocking          是否按住格挡
blockElapsed      本次格挡持续时间
parryCooldown     弹反冷却
guardBreakLeft    破防硬直
```

- T2 落地补充：`CombatStance` 还携带 `blockReduction`/`blockStaminaCost` 两个装备派生覆盖字段（`<0` 表示使用全局配置），供 T4/T6 写入；不进入存档，T9 起姿态同步字段进入 `ZLR1` 复制。

规则：

- `LCTRL` 按住格挡；格挡时移动速度 ×0.65，不能攻击/重击/闪避。
- 只有来自正面约 140° 扇区内的 `Claw/Bite/Blunt` 伤害可格挡；`Fire/Debug` 不可格挡。
- 普通格挡：伤害 ×0.35、击退 ×0.50；每次格挡消耗 `clamp(8 + weight*3, 10, 30)` 体力；武器可用 `blockReduction/blockStamina` 覆盖减伤和消耗。
- 弹反窗口：开始格挡后的 **0.18 秒**内；窗口内成功格挡：
  - 伤害归零、无伤口/感染/击退；
  - 攻击者获得 `0.55` 秒硬直（通过其 `HitReaction`/`ActionState`）；
  - 消耗 **6** 点体力，弹反进入 **0.70 秒**冷却。
- 体力不足以支付格挡消耗时触发 **破防**：
  - 不减免本次伤害；
  - 目标 `staggerLeft=0.80`，格挡强制关闭，0.80 秒内不能重新格挡；
  - 显示 `破防` 提示。
- 格挡方向使用目标 `Facing`；攻击方向取 `DamageEvent.dir`（攻击者→目标），`dot(facing, -dir)` 判定正面。
- 格挡反馈通过 `CombatSystem` 回调交给 game 层：普通格挡播放金属/钝击占位音与火花；弹反播放更亮的火花/提示。服务器在 T6 负责权威结算，客户端只显示。

### 3.5 闪避

新增 `CombatStance` 字段：

```text
dodgeLeft        剩余闪避时间
dodgeInvulnLeft  剩余无敌时间
dodgeDirX/Y      闪避方向
dodgeCooldown    闪避冷却
```

规则：

- `Z` 起手；方向取当前 WASD 输入，没有输入时取面向。
- 消耗 **18** 体力，冷却 **0.65 秒**，持续 **0.28 秒**，其中前 **0.18 秒**无敌。
- 闪避期间不能攻击/格挡；无敌期间 `ApplyDamage` 直接返回 false，不写伤口/感染/疼痛/硬直。
- 位移复用现有 `MoveIntent`/`MovementSystem`：`CombatSystem` 在闪避期间写入 `MoveIntent = dir * (1.5 / 0.28)`，结束后恢复输入控制；不新增物理系统。
- 撞墙/障碍仍由 `MovementSystem` 处理，不穿墙。
- 服务器权威：闪避命令只带方向，服务器扣体力/设冷却/推进无敌帧；客户端显示 `闪避` 提示，不本地决定伤害免疫。

### 3.6 伤害结算顺序

`CombatSystem::ApplyDamage` 统一顺序：

1. 目标无效/已死亡 → false。
2. 闪避无敌 → false，不写伤口/感染/硬直。
3. 正面格挡/弹反 → 调整伤害、体力、攻击者硬直；弹反直接 false。
4. 护甲/僵尸变体/车辆乘员减伤。
5. 扣血、伤口、感染暴露、疼痛。
6. 硬直条扣除与破防长硬直。
7. 击退/闪红/`ActionState`/死亡统计。

- 格挡/弹反只对玩家/带 `CombatStance` 的实体生效；AI 默认没有格挡。
- 伤害反馈回调新增 `BlockFeedback`，避免把“格挡成功”误算成命中；现有 `m_hits` 只在真实扣血时记录。

## 7. 风险与处理

| 风险 | 处理 |
|---|---|
| 范围膨胀成完整动作游戏 | 固定 T1–T9；不做部位、连招、盾牌、正式动画 |
